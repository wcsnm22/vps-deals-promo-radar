The file

Download unit-price.csv

The CSV is written by the same build that renders this page, so it always matches the price table on the site. Columns: provider, plan, price, currency, ram_gb, vcpu, disk_gb, price_per_gb_ram, price_per_vcpu, unit_price_formula, source_url, fetched_at.

What is in it and what is not

A row carries a per-GB number only when the provider published a RAM figure in the same place as the price. Rows without a published RAM figure keep that cell empty on purpose: a headline price on its own cannot be converted into a per-GB figure without inventing the denominator.

How to recompute any row yourself

Every per-unit cell equals price ÷ ram_gb (or price ÷ vcpu). The unit_price_formula column spells out the arithmetic for the row, and source_url plus fetched_at say which public page it was read from and when.
