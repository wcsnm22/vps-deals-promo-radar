# 申请话术模板（可直接粘贴进联盟申请表）

用途：联盟/厂商申请表里那些问"你是谁、你怎么推广、你的流量从哪来"的字段，照下面填。

**底线**：不夸大流量。审核的人会去 GSC/GA4 或第三方工具核；数据对不上，账号会被封，而且这行圈子小。
下面的方括号 `[...]` 是你要填的真实值。

---

## 1. 站点描述（Description / About your site，常限 200-500 字符）

```
VpsDealsRadar is an independent price tracker for VPS plans. It reads prices that hosting providers
publish on their own public pages and republishes them with the source page and the exact UTC read
time, refreshed on a schedule. It adds what provider pages usually leave out: a downloadable price
table (CSV), per-unit pricing computed from published figures, and numbered setup walkthroughs.
No prices are estimated or converted, and no provider can pay for placement.
```

## 2. 推广方式（Promotion method / How will you promote us）

```
Content and comparison pages targeting people actively shopping for a VPS. Traffic comes from organic
search. Each provider gets a dedicated page listing every plan we could read from their public pricing
page, with a direct link to that plan. We do not use paid traffic, email, incentivised clicks, coupon
sites, pop-unders or toolbars.
```

## 3. 流量来源与现状（Traffic — 如实填，别吹）

```
Traffic source: organic search only.
Site age: launched [上线日期].
Google Search Console: [N] pages indexed as of [日期]; [N] clicks and [N] impressions in the last 28 days.
Google Analytics 4: [N] active users in the last 28 days (measurement ID G-[...], installed [日期]).
Content: [N] pages, updated [频率，例如 daily].
```

> 如果数字是 0 就写 0。**"新站、刚开始、数字还很小"本身不是拒你的理由，撒谎才是。**

## 4. 为什么要加入（Why do you want to join / Motivation）

```
Our readers arrive with a buying decision already half made — they want to know what a specific plan
costs before they buy. We want a tracked link so we can see which plans actually get clicked, and we
will disclose affiliate relationships on every page.
```

## 6. 如果又被拒，怎么问原因

Awin 不解释拒因是常态。可以发一封**简短、不纠缠**的邮件或工单：

```
Subject: Re: application [申请编号]

Thanks for reviewing. I would like to reapply later with a stronger site, so a one-line pointer would
help: was the application declined mainly because of (a) insufficient traffic, (b) site content, or
(c) missing information?

Site: https://vpsdealsradar.com
Current Google Search Console: [N] pages indexed, [N] clicks / [N] impressions (28 days)
Google Analytics 4: [N] active users (28 days)

Happy to wait and reapply once the numbers are there.
```

## 7. 优先级建议（不靠等平台）

| 顺序 | 做什么 | 为什么 |
|---|---|---|
| 1 | 直接申请**厂商直营**计划：netcup、RackNerd、OVHcloud | 门槛低于平台，能立刻拿到链接 |
| 2 | 链接上线后，开始积累**出站点击**数据 | 这是你独有的证据，平台最爱看 |
| 3 | 有 1-2 个月真实流量后，再申请 Awin / DigitalOcean | 那时你有数据可给对方看 |

**不要**同时向多个平台申请同一家厂商的计划，容易触发风控。
