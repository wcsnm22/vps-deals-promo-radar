About VpsDealsRadar

{{site_title}} is an independent price tracker for VPS (virtual private server) plans. It does one job: it reads the prices that hosting providers publish on their own public pages, and shows them with the source page and the exact UTC time each number was read.

Written and maintained by an independent developer, for people who need a straight answer about what a small server costs. This site is not affiliated with, endorsed by, or operated by any of the hosting providers it lists, and no provider can pay to change a price or to be included.

What is on this site today

  • {{offer_count}} plans across {{provider_count}} providers, each with the page and UTC read time it came from.
  • {{guide_count}} guides covering what provider pages usually leave out: a downloadable price table, per-unit pricing computed from published figures, and a numbered setup walkthrough.
  • A side-by-side price list, a downloadable CSV, and a methodology page describing how every number is read.
  • The dataset is refreshed on a schedule (currently every six hours). Each price is dropped the moment it can no longer be read from the provider's page, rather than carried over from an earlier run.

What this site does

  • Reads public provider pages on a schedule (currently every six hours).
  • Checks each provider's robots.txt first and skips any page a provider has disallowed; skipped providers are recorded in the dataset instead of being guessed at.
  • Links every listed price back to the page it came from, together with the time it was read.
  • Keeps each price in the currency the provider published it in.

What this site does not do

  • It does not invent, estimate or round prices. If a provider publishes no readable price for a plan, that plan is listed with no price at all.
  • It does not convert currencies or add "approximate" figures.
  • It does not publish coupon codes it cannot verify.
  • It does not scrape behind a login, and it does not try to defeat anti-bot protection.
  • It does not accept payment for placement, and no provider sees a listing before it is published.

How it runs

The whole pipeline is a small, deterministic Python program: one script fetches the provider pages and writes a dataset, another renders this static site from that dataset. It runs on a schedule with no server, no database and no runtime model calls. The full source is public at {{repo_url}}.

How this site is funded

Commission never changes the prices shown here, and it never changes which plans are listed. No provider can pay to be included or to move up.

How the numbers are read

The full method — what is fetched, what is discarded, and what is never done — is written out on the methodology page. In short: one published number at a time, with its source page and timestamp, and nothing invented to fill a gap.

Corrections

Prices change without notice and pages get rewritten. If a number here looks wrong, please write to contact@vpsdealsradar.com and it will be checked against the provider's own page.
